ころたまの 音（オルゴール案）

曲は OK・音色が 安っぽい（2026-10-10）→ 音色を 作り直して 3つ ならべました。2026-10-10 の 壁打ちで 決めた 案B：おうちと できた！の 画面だけ オルゴール、もんだいの 画面は 小鳥と 風の 音だけ、声の あいだは 音楽を 小さく。効果音も 木琴と 鈴に 作り直しました。公開は この ページを 聞いて もらってからです。音は アプリの 中で その場で 作る ものと 同じ 作り方で 書き出しました。

音色を えらぶ（同じ 曲の はじめ 18秒）

前の 版は 正弦波だけで「ファミコンみたい」でした。つめを はじく 音・金属の にごり・木の 箱の ひびき・部屋の ひびきを 足して 3つ 作りました。

A オルゴール（ガラスの きらめき）
B カリンバ（あたたかい・丸い）
C オルゴールの つめ（にごりあり）

声と いっしょに（音楽が 小さく なる ところ）

音楽の 大きさ：ふつう。声が 始まると 3わりまで 下がり、おわると ゆっくり もどります。

できた！（ジングル → おうちの 曲を 小さく）

スタンプが つく 画面。あかるい 4拍子の ジングルを 1回 鳴らして、そのあと おうちの 曲が 小さく つづきます。

もんだいの 画面（音楽なし・小鳥と 風）

ごはん・おみせ・あそぶ・くらべっこ・もじ・とけい の あいだ。声の じゃまを しない ように、ほとんど 聞こえない くらいの 風と、5〜12秒に 1回の 小鳥だけです。タブレットの スピーカーで 聞こえるか どうかが 気に なる ところです。
