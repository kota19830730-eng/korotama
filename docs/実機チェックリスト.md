## 1. 声（はじめの 画面）

- [ ] 「はじめる」→ おうちの人の 設定で **「声を ためす」** を おすと、ずんだもんの 声が 出る
- [ ] あそびの 中でも ずんだもんの 声で 話す（名前は 声では よばない・字幕には 出る）
- [ ] 音が 出ない ときは 消音を 切る。それでも だめなら 設定を「端末の 声」に して ためす

## 2. カメラ（紙の 絵を 写真に とる）

- [ ] 「絵を 入れる」→「紙の 絵を 写真に とる」で **カメラが ひらく**（許可を きかれたら「許可」）
- [ ] 白い 紙に 太めの 線で かいた 絵を、明るい ところで 1まいだけ うつす
- [ ] 「この すがたで いい？」に **「そのまま」と「絵本ふう」** の 2まいが 出る（うすい えんぴつでも 線が 見える か）
- [ ] 暗い ところで とると「もう一度 明るい ところで」の 注意が 出る

## 3. ゆびで かく

- [ ] 「画面に ゆびで かく」で、ゆびの 動きに 線が **おくれず・切れず** ついてくる
- [ ] クレヨンの 色を かえられる・けしゴムで 消せる
- [ ] 「できた！」→ 2まいが 出る → 名前 →「たまごに する」

## 4. あそび（3歳の 子と）

- [ ] たまごを 3回 とんとん → かえる（声と 音）
- [ ] おうちで「ごはん」「あそぶ」「おみせ」の ボタンが ゆびで おせる 大きさ か
- [ ] まちがえても ばつが 出ず、声で 正しい ほうを 教えて くれる
- [ ] 3問で「できた！」→ スタンプが 1つ ふえる

## 5. 成長の 姿

- [ ] おうちの人の 画面（右上の かぎを 長おし）→「ぜんぶの スタンプ」が 6こに なると 2段階め、15こで 3段階め に 絵が かわる（キャラクターは 体が 立派に・子どもの 絵は 大きく＋はね）

- カメラが ひらかない：ブラウザの 設定で カメラを 許可。だめなら「画面に ゆびで かく」で
- 画面が 古い まま：いちど とじて ひらき直す（新しい 版は 自動で 入れかわります）
