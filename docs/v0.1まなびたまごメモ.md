# まなびたまご v0.1 メモ（2026-10-09）

3〜6歳向けの知育ゲーム。まなびモンスター（manabi-quest/）の部品で作った**別アプリ**。名前「まなびたまご」は仮。

## 決めごと（ユーザー決定 2026-10-08）
- 対象 3〜6歳（3段階：ちいさい 3〜4／なかくらい 4〜5／おおきい 5〜6。おうちの人が設定）
- 別アプリ・別フォルダ（`manabi-tamago/`）。共通の部品はコピーして持ちこむ
- 親といっしょに遊ぶ前提。ひとりでも遊べるように「字幕と声かけヒントを出さない」設定あり
- 指示は全部 声（Web Speech API・日本語・**高めの声 pitch 1.35**）。声が入っていない端末では字幕をかならず出す
- ~~最後はまなびモンスターに連れていく~~ → **まなびモンスターへ つれていく は なし（ユーザー決定 2026-10-09「あまりにも 世界観が 違う」）**＝ボタン・exportMon は 消した。まなびたまごは それだけで 完結する アプリ。
- 見た目は A案「あたたかい絵本ふう」（見本 https://claude.ai/artifact/UqVqkMtqAKBJ3BZHU3ZZD8 ）
- テスター：3歳の男の子（お客様のお子さん）→ まず「ちいさい」をしっかり

## 幼児向けの大原則
- 子どもの画面に**字はいらない**（字幕はおうちの人が読む）。ことばは全部ひらがなで、数は「ひとつ・ふたつ・みっつ」
- ボタン 64px 以上・タップだけ（ドラッグなし）・2〜5択
- **ばつなし**。まちがえたら声で正しいほうを教える（教える段階＝まなびモンスターの「答えを見せない」とは逆）
- 「ほっとくと死ぬ」は作らない。1回の遊びは 3問で終わる
- 写真も記録も外に送らない

## 遊びの流れ
1. はじめ → おうちの人の設定（名前・段階・声の高さ・声のテスト）
2. 絵を入れる：紙の絵を写真（`<input capture>`）か、画面にゆびでかく（クレヨン 5色＋けしゴム）
3. ブロックのすがた（`MQ.trace`＝photo.js の traceCells／coolTrace をそのまま）→「そのまま／かっこよく」を選ぶ → 名前
4. たまご（絵の色が模様になる）→ 3回とんとん → かえる → おうち
5. おうち：ごはん（かず）／あそぶ（かたち）／おみせ（いろ＋かず）。3問で「できた！」＝スタンプ 1つ（1日 5こまで）
6. スタンプ合計 6こで 2段階め・15こで 3段階め（monstergen.evoPng で作った png2／png3）

## 3段階の中身（js/core/tasks.js）

| ごはん（かず） | 1〜3・くぼみあり | 1〜5・くぼみあり | 1〜10・くぼみなし（生きものをタップして「あげる」・多い／少ないを声で） |

## v0.1.6 声の イントネーション（2026-10-09）
ユーザー「話し方、イントネーションが おかしい。違和感ある」→ 原因は 2つ と 見た：①文節ごとの スペース（「きょうは なにを する？」）で 声の エンジンが 単語ごとに 切って 読む ②ぜんぶ ひらがな なので ことばの 切れ目と アクセントを まちがえる（「なにを」「あそぼう」）。
- `js/core/voice.js` の **spokenForm()**：読む 直前に **ひらがな → かん字**（まなびモンスターの 辞書 `js/content/kotoba.js`＋`js/content/kakusu.js`＋`js/core/text.js` の `_up` を 2回・学年 6）→ **スペースを 外す**。**画面の 字幕は 変えない**（text.js の 自動 watch() は 外して ある＝子どもの 画面に 字は いらない の きまりは そのまま）。
- はじめの 声を **ふつう（pitch 1.0）**に（高めは 1.1。ピッチを 上げるほど 機械っぽく なる）。ゆっくり 0.78／ふつう 0.9。
- 変換の 一覧は scratchpad の dump.js で 目で 読んだ（「あげる→上げる」は 同じ 読み・「とりなおす→鳥なおす」は ボタンの 字で 読まない）。smoke「声に 出す 形」「読む 文は かん字・スペースなし」。sw v7。

## v0.1.7 ずんだもんの 声（録音）（2026-10-09）
ユーザー「音声 AI の 種類 変えれないの？ ずんだもんとか フリーの あるやん」→ ブラウザの 中で 動く 声は 端末の 声（Web Speech）しか ない ので、**VOICEVOX の ずんだもん を PC で 録音して アプリに 入れる** 方式に した。
- **文の 一覧** `tools/voice/lines.js` → `lines.json`（もんだいの 型 × 色・もの・数 を ぜんぶ 組み立て＋画面の say の 文＝**317文**。「。！？」で 区切った 1文ずつ）。文を 足したら lines.js → render.js。smoke が「画面の say の 文が ぜんぶ 一覧に ある」ことを 見る。
- **録音** `tools/voice/render.js`：VOICEVOX（winget `HiroshibaKazuyuki.VOICEVOX.CPU`・エンジンは `%LOCALAPPDATA%/Microsoft/WinGet/Packages/HiroshibaKazuyuki.VOICEVOX.CPU_…/VOICEVOX/vv-engine/run.exe`）の HTTP API（audio_query → synthesis・speaker 3＝ノーマル・speedScale 0.95・intonationScale 1.1）→ WAV → ffmpeg（winget `Gyan.FFmpeg`）で **48kbps モノラル mp3**（1文 約6〜10KB・ぜんぶで 約3MB）→ `assets/voice/NNN.mp3`＋`bank.json`。
- **再生** `js/core/voice.js`：`kind`（'zunda'＝はじめ／'device'）。say() は 文ごとに bank を 引き、あれば Web Audio（AudioContext・decodeAudioData・最初の タップで resume）で 鳴らし、**無い 文だけ 端末の 声**。**名前は 録音に 無い ので 読む 前に 外す**（`setNames`＝お子さんの 名前＋'ちゃん、'・生きものの 名前＋'だよ。'／'が '／'も '…）。「○○も うれしいって」→「○○も うれしいよ」に 文を 変えた（名前を 外しても 通る 形）。
- **設定**：はじめの 画面と おうちの人の 画面に「ずんだもん／端末の 声」。高さ・はやさは 端末の 声の ときだけ。おうちの人の 画面に クレジット「声：VOICEVOX：ずんだもん」。`assets/voice/README.md` にも。
- **sw.js**：`assets/voice/` は 使った 文から キャッシュ（FILES に 1つずつ 書かない）。sw v8。
- 通信は しない（mp3 は アプリと いっしょに 配る）。ライセンス：ずんだもんは クレジット表記で 商用・非商用とも 利用可（VOICEVOX の 利用規約）。
