# まなびたまご v0.1 メモ（2026-10-09）

3〜6歳向けの知育ゲーム。まなびモンスター（manabi-quest/）の部品で作った**別アプリ**。名前「まなびたまご」は仮。

## 決めごと（ユーザー決定 2026-10-08）
- 対象 3〜6歳（3段階：ちいさい 3〜4／なかくらい 4〜5／おおきい 5〜6。おうちの人が設定）
- 別アプリ・別フォルダ（`manabi-tamago/`）。共通の部品はコピーして持ちこむ
- 親といっしょに遊ぶ前提。ひとりでも遊べるように「字幕と声かけヒントを出さない」設定あり
- 指示は全部 声（Web Speech API・日本語・**高めの声 pitch 1.35**）。声が入っていない端末では字幕をかならず出す
- 最後はまなびモンスターに連れていく（生きもののデータは `p.custom` と同じ形）
- 見た目は A案「あたたかい絵本ふう」（見本 https://claude.ai/artifact/UqVqkMtqAKBJ3BZHU3ZZD8 ）
- テスター：3歳の男の子（お客様のお子さん）→ まず「ちいさい」をしっかり

## 幼児向けの大原則
- 子どもの画面に**字はいらない**（字幕はおうちの人が読む）。ことばは全部ひらがなで、数は「ひとつ・ふたつ・みっつ」
- ボタン 64px 以上・タップだけ（ドラッグなし）・2〜5択
- **ばつなし**。まちがえたら声で正しいほうを教える（教える段階＝まなびモンスターの「答えを見せない」とは逆）
- 「ほっとくと死ぬ」は作らない。1回の遊びは 3問で終わる
- 写真も記録も外に送らない

## 遊びの流れ
1. はじめ → おうちの人の設定（名前・段階・声の高さ・声のテスト）
2. 絵を入れる：紙の絵を写真（`<input capture>`）か、画面にゆびでかく（クレヨン 5色＋けしゴム）
3. ブロックのすがた（`MQ.trace`＝photo.js の traceCells／coolTrace をそのまま）→「そのまま／かっこよく」を選ぶ → 名前
4. たまご（絵の色が模様になる）→ 3回とんとん → かえる → おうち
5. おうち：ごはん（かず）／あそぶ（かたち）／おみせ（いろ＋かず）。3問で「できた！」＝スタンプ 1つ（1日 5こまで）
6. スタンプ合計 6こで 2段階め・15こで 3段階め（monstergen.evoPng で作った png2／png3）

## 3段階の中身（js/core/tasks.js）
| | ちいさい | なかくらい | おおきい |
|---|---|---|---|
| ごはん（かず） | 1〜3・くぼみあり | 1〜5・くぼみあり | 1〜10・くぼみなし（生きものをタップして「あげる」・多い／少ないを声で） |
| おみせ（いろ） | 色 3・1〜2こ | 色 4・1〜3こ | 色 5・2〜4こ |
| あそぶ（かたち） | 2択 | 3択 | 4択＋色（同じ形で色ちがいが 1つまざる） |

## 生きもののデータ（まなびモンスターと同じ形）
`kid.mon = { id:'my-…', name, area:'sansu', png, png2, png3, trace:true, from:'tamago' }`
「つれていく」＝ `{ app:'manabi-tamago', v:1, name, mon, stamps }` を JSON で保存。**まなびモンスター側の読みこみは未実装**（つぎの版で「まなびたまごから つれてくる」を足す）。

## v0.1.1 キャラクターから えらぶ（2026-10-09）
ユーザー「書いた絵が出るのはいいけどデフォルトでかっこいいのと可愛いキャラクターが選べるとか欲しい」→ `js/content/presets.js`＝かわいい 8体（うさぎ・ねこ・ひよこ・ペンギン・くま・ぶた・ひつじ・カエル）／かっこいい 8体（ドラゴン・ロボット・ライオン・サメ・オオカミ・きし・にんじゃ・ロケット）。絵は monstergen の 体の 形で その場で 組み立てる（手で 座標を 打たない）。「絵を 入れる」画面の 3つめの ボタン → えらぶ → 名前 → たまご。mon.preset に id・trace は false。harness `#presets[:cool[:pick]]`・sw v2。
