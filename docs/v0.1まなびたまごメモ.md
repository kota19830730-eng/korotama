# まなびたまご v0.1 メモ（2026-10-09）

3〜6歳向けの知育ゲーム。まなびモンスター（manabi-quest/）の部品で作った**別アプリ**。名前「まなびたまご」は仮。

## 決めごと（ユーザー決定 2026-10-08）
- 対象 3〜6歳（3段階：ちいさい 3〜4／なかくらい 4〜5／おおきい 5〜6。おうちの人が設定）
- 別アプリ・別フォルダ（`manabi-tamago/`）。共通の部品はコピーして持ちこむ
- 親といっしょに遊ぶ前提。ひとりでも遊べるように「字幕と声かけヒントを出さない」設定あり
- 指示は全部 声（Web Speech API・日本語・**高めの声 pitch 1.35**）。声が入っていない端末では字幕をかならず出す
- 最後はまなびモンスターに連れていく（生きもののデータは `p.custom` と同じ形）
- 見た目は A案「あたたかい絵本ふう」（見本 https://claude.ai/artifact/UqVqkMtqAKBJ3BZHU3ZZD8 ）
- テスター：3歳の男の子（お客様のお子さん）→ まず「ちいさい」をしっかり

## 幼児向けの大原則
- 子どもの画面に**字はいらない**（字幕はおうちの人が読む）。ことばは全部ひらがなで、数は「ひとつ・ふたつ・みっつ」
- ボタン 64px 以上・タップだけ（ドラッグなし）・2〜5択
- **ばつなし**。まちがえたら声で正しいほうを教える（教える段階＝まなびモンスターの「答えを見せない」とは逆）
- 「ほっとくと死ぬ」は作らない。1回の遊びは 3問で終わる
- 写真も記録も外に送らない

## 遊びの流れ
1. はじめ → おうちの人の設定（名前・段階・声の高さ・声のテスト）
2. 絵を入れる：紙の絵を写真（`<input capture>`）か、画面にゆびでかく（クレヨン 5色＋けしゴム）
3. ブロックのすがた（`MQ.trace`＝photo.js の traceCells／coolTrace をそのまま）→「そのまま／かっこよく」を選ぶ → 名前
4. たまご（絵の色が模様になる）→ 3回とんとん → かえる → おうち
5. おうち：ごはん（かず）／あそぶ（かたち）／おみせ（いろ＋かず）。3問で「できた！」＝スタンプ 1つ（1日 5こまで）
6. スタンプ合計 6こで 2段階め・15こで 3段階め（monstergen.evoPng で作った png2／png3）

## 3段階の中身（js/core/tasks.js）
| | ちいさい | なかくらい | おおきい |
|---|---|---|---|
| ごはん（かず） | 1〜3・くぼみあり | 1〜5・くぼみあり | 1〜10・くぼみなし（生きものをタップして「あげる」・多い／少ないを声で） |
| おみせ（いろ） | 色 3・1〜2こ | 色 4・1〜3こ | 色 5・2〜4こ |
| あそぶ（かたち） | 2択 | 3択 | 4択＋色（同じ形で色ちがいが 1つまざる） |

## 生きもののデータ（まなびモンスターと同じ形）
`kid.mon = { id:'my-…', name, area:'sansu', png, png2, png3, trace:true, from:'tamago' }`

## v0.1.2 キャラクターを 絵本ふうに（2026-10-09）

## v0.1.3 絵本ふうの キャラクターの 成長の 姿（2026-10-09）
v0.1.2 で「SVG の キャラクターは 2・3段階めの 絵が なし」だった のを うめた。絵は 変えず、頭の 上に かざりを 足す＝**2段階め（スタンプ 6こ）＝リボン＋きらきら 2つ／3段階め（15こ）＝金の かんむり＋きらきら 3つ**。リボンの 色は かわいい＝ピンク・かっこいい＝青。`MQ.charart.svg(id, grade)`／`url(id, grade)`・かんむりの 場所は `HEAD[id] = [x, y, はば, かたむき]`（耳・つの・ひれを よける。サメと ロボットは ななめに）。presets.js が png2／png3 を 持ち、`MQ.ui.makeMon(png, name, cb, preset)` が セーブに 入れる → `MQ.save.monPng()` が いままで どおり 段階で 切りかえる。1回めは かんむりが 小さすぎた（はば 12〜14）→ 1.4倍に。harness `#pmon:<id>:2|3`（スタンプを 入れて おうちで 見る・shown=true が 合格）・smoke「charart」の 節・sw v4。見た目は scratchpad の charsheet.js（16体×3段階 を 1まいに）・見せた ページ https://claude.ai/artifact/Y8XNeSHbdchFturL8LCLsT 。子どもの 絵（ブロック）の 2・3段階めは いままで どおり evoPng。

## v0.1.4 姿が 立派に なる 成長 ＋ 子どもの 絵は そのまま／絵本ふう ＋ 公開（2026-10-09）

- **成長（charart.js）**：`ART[id](gr)` が 1 ちび（小さく まるい・0.78倍）／2 こども（体が のびて 手足・しっぽ・はね・0.9倍）／3 立派（大きく・その 生きもの らしい 見せ場＝うさぎ 長い 耳と きば・ねこ しま模様と きば・ひよこ→にわとり（とさか・大きな つばさ・尾羽）・ペンギン→皇帝（金の 首）・くま 立ち上がって つめ・ぶた→いのしし（きば・たてがみ）・ひつじ→ひつじの 王（巻き角）・カエル 大きな 後ろ足と もよう／ドラゴン 大きな つばさ・背びれ・ほのお・ロボット 肩キャノンと ジェット・ライオン 二色の 大たてがみ・サメ 大きな ひれと 6本の 歯・オオカミ 白い たてがみと きば・きし マントと 大剣・にんじゃ 二刀と 手裏剣・ロケット ブースター）を 描き分ける。**かざりを のせる 方式（v0.1.3）は やめた**。smoke が「ribbon／crown が ない」ことを 見る。
- **子どもの 絵（js/core/cutout.js・新）**：trace.js の 紙を 見つける 道具（`MQ.trace.parts`）を 借りて、**そのまま**（紙を 消した 切りぬき・うすい えんぴつは 紙との 差で こく・ふちは やわらかく）と **絵本ふう**（線は「紙より しきい値ぶん 暗い」で 見分け、色は クレヨンの 11色＋こげ茶に そろえ、7×7 の 多数決で ぬりむらを 平らに、線は まわりの 色の こい色＝黒い ふちなし）の 2まい。成長は **大きさ（0.78／0.9／1.0）＋ 2段階めから はね（3段階めは 金の 大きな はね）**。64マスの ブロック（traceCells・monstergen.evoPng）は もう 使わない（index／sw から monstergen.js を 外した）。`.bxbox__png` の pixelated も やめた。

## v0.1.5 3段階めを かわいく ＋ 声を ゆっくり（2026-10-09）
