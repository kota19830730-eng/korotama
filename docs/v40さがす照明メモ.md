ユーザー「照明が くらかったり オレンジよりの 色だと 色や 形を 正しく 認識しない」。
- 形（まるい・しかくい）は もともと 自動で 読んで いない（おうちの人が 長おしで ○）。今回は 色だけ。
- js/core/find.js `balance(px, w, h)` を classify の 前に：光の 強さ（線形）で ①明るい 上位 2わりの 白っぽい 点で 光の 色を 打ち消す（ずれ 15% いかは しない）②白っぽい ところが 3% 未満なら 色は かえない（写真 ぜんたいの 平均は ものの 色を 消す）③明るい 点が sRGB 150 未満の ときだけ 明るく（色あいを かえない）。`MQ.find.lastFix()` で 補正の 値。
- 測り方：作業場の `未就学児アプリ/さがすテスト/`（Commons の 写真 38まい・テスト用だけ・配布しない）。`bash run.sh` → out.txt（old＝git HEAD の find_old.js）。光は 線形で かける：暗い −2.7EV／電球色 r1 g0.74 b0.45。
