# v0.1.17 写真の 主役を 切りぬく（ぬいぐるみ・おもちゃ）メモ（2026-10-10）

## きっかけ

ユーザーが 子どもの ぬいぐるみ（うさぎ）を 床の 上で 撮って ためした →「できた キャラクターの クオリティが あまりにも ひどい」。
画面には **床ごと 四角の 写真**が キャラクターとして 出て いた（ぬいぐるみは まん中に 小さく）。
ユーザー「周りの 背景を 消したり、判定が 粗末」→ 案 A（仕組みを 広げる）＋B（案内）で「おすすめは A＋B で」。

## なぜ ひどかったか

いままでの `js/core/cutout.js` は **白い 紙に かいた 絵 専用**：紙の 白を 見つけて 消し、のこりが 絵。
床・机・布の 上の ぬいぐるみは「紙」が 見つからず、写真ぜんぶが 絵に なった。

## 作ったもの

### A　`js/core/subject.js`（新・`MQ.subject`）＝写真の まん中の「もの」を 切りぬく

`MQ.ui.draw.fromImage`（start.js）が 写真の とき `MQ.subject.isPaper(img)` で 分ける：
- 紙らしい（写真ぜんたいの うち「明るい ほう 3割に 入り・色みが 小さい」点が **35% いじょう**）→ いままでの cutout（紙の 絵）
- それ以外 → subject（ぬいぐるみ・おもちゃ）。白い 紙・白い 布の 上の ぬいぐるみは 紙あつかいに なるが、いままでの 道で ちゃんと 抜ける

subject.mask の 手順（320px で しらべる）：
1. **色の 特徴**＝明るさ L と、**明るさで わった 色み**（赤み・青み）。明るさで わる ので、ランプの 近くの 明るい 床と ふちの 暗い 床が 同じ 色に なる（影・光の むらに 強い）。きょりは L を 半分に 数える
2. 暗い 写真は さきに 明るさ（2〜98%）を 0〜255 に のばす（倍率 4 まで・1.8 をこえたら 1-2-1 で ならす）
3. **背景の 色**＝ふちの 帯（外がわ 8%）を 4色に まとめ、①いちばん 多い 色の 4分の1 いじょう ②ふちの 8つの 区切りの うち 5つ いじょうに ある ③まん中の 箱での わりあい ÷ ふちでの わりあい が 1.3 みまん、を ぜんぶ 満たす 色だけ。
   （②＝大きく とった ぬいぐるみが ふちに かかって いても 背景に しない／③＝ふちの 6割が ぬいぐるみ でも 背景に しない／光の 反射（帯の 7%）は ①で 落ちる）
4. **背景と 主役の「かけっこ」（測地きょり・ダイクストラ）**：背景の 出発点＝ふちの 点の うち 背景の 色に ちかい もの＋どこでも 背景の 色に とても ちかい 点。主役の 出発点＝背景から 遠い 点の いちばん 大きな かたまり（写真ぜんたい・大きさ × まん中への 近さ）。となりへ すすむ コスト＝（となりとの 色の 差 と 2px の へり E の 大きい ほう）の **4乗**＋0.02。先に とどいた ほうの なかまに なる
   - ふちから 広げるだけ だと、へりの すきま 1つで ぬいぐるみ ぜんぶが 背景に なった（すみに よせた うさぎで 実測）→ かけっこに した
5. のこった 中の **床の 大きな かたまり**（背景の 色に まあまあ ちかい 点が 400 いじょう つながる）→ 背景へ
6. **床の 島**（板の すじで かこまれて とどかなかった 床・その 中の 光の 反射）：2px けずって 橋を 切り、かたまりごとに ①中身の 半分が 背景の 色 ②2色に まとめた 多い ほうが 背景に ちかい ③へりを はさんだ 内がわ 3px と 外がわ 6px（外が 背景の 色の ときだけ）が 同じ、の どれかなら 背景へ
7. **主役**＝大きさ × まん中への 近さ × へりの はっきりさ で いちばんの かたまい＋近くの 小さな かけら（へりの はっきりさが 主役の 半分いじょう の もの だけ）。細い 板の すじは 開く（erode→dilate）で 落とす
8. 色の 手本（主役＝内がわ・背景＝外がわ）で へりの 帯 ±6px を 2回 見なおす
9. 影：背景の 色に ちかく、主役の 色に ない 点は 背景へ（3×3 の 多数決は かけない＝細い 影が もどって しまう）
10. あなを うめる

絵に する：`levels`（主役の 中の 明るさ 2〜98% を 16〜250 に・色みを 1.2倍）→ そのまま（ふち 1px やわらか）／絵本ふう（8色に まとめ・5×5 の 多数決・目／口／ほっぺは のこす）→ `MQ.cutout.stages` で 3段階（はね）。

### B　案内（start.js）

- 絵を 入れる 画面：「ぬいぐるみや おもちゃも OK：床や 机の 上に 1つだけ おいて、まん中に 大きく うつる ように とります。うまく 切りぬけない ときは、白い 紙や 白い 布の 上に おくと きれいに なります」
- 見つからない とき：「なにを とったか わかりません。白い 紙か 白い 布の 上に おいて、明るい ところで とってね」
- えらぶ 画面（もの の とき）：「まわりが のこって いたり 一部が 消えて いたら、白い 紙や 白い 布の 上に おいて とりなおすと きれいに なります」

## 気をつける こと（もどさない）

- 色みは 明るさで わる（わらないと 明るい 床が 背景から 外れて 島に なる）
- 背景の 色の 3つの 条件（多さ・広がり・まん中との 比）を 外さない
- かけっこの コストは 4乗（3乗だと なだらかな 影の へりで 背景が 勝った）・E も 見る
- 影の 段階で 多数決を かけない
- 「ふちから 広げる」方式（reach）に もどさない
